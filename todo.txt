项目背景
你正在协助开发 My_Teacher v4 —— 一个从“AI 教师应用”升级为“AI 自适应教学系统”的开源项目。

当前 v3 已实现的功能：

Flask 后端（app.py）提供对话、备课、测验、代码执行等 API

前端单页应用（Galgame 风格 + Live2D 虚拟老师）

本地 Ollama / 云端模型双通道

课程管理（备课 → 分课 → 测验 → 进度）

TTS 语音朗读、图片/文本附件上传

v4 的升级目标：
从“LLM-centric 对话式老师”升级为“Learner-centric 自适应教学系统”。

核心升级方向：

建立学生数字孪生（Learner Digital Twin）

建立知识图谱（Knowledge Graph）

拆分多 Agent 系统

建立学习效果评估闭环

实现基于学生状态的自适应学习路径推荐

任务三：建立 Pedagogical Engine（教学策略引擎）
在 project/ 目录下新建 pedagogical_engine.py，实现教学策略决策逻辑。

核心功能：

诊断引擎（Diagnosis Engine）

输入：学生答题记录、测验结果、对话历史

输出：知识漏洞列表、薄弱点分析

函数：run_diagnosis(learner_id, course_id) → 返回诊断报告

规划引擎（Planning Engine）

输入：学生当前状态、学习目标

输出：下一课推荐、学习路径调整建议

函数：plan_next_lesson(learner_id, course_id) → 返回推荐的下一个单元

自适应策略（Adaptive Strategy）

规则示例：

如果连续答错 2 题 → 切换教学方式（换类比、换例子）

如果连续答对 3 题 → 推进到下一个知识点

如果掌握度 < 0.5 → 重讲 + 更多练习题

如果掌握度 > 0.8 → 跳过基础练习，直接进入应用层

需要实现的函数：

adapt_teaching_strategy(learner_id, context) → 返回教学策略建议

should_advance(learner_id, concept_id) → 判断是否应该推进到下一个概念

get_next_action(learner_id, current_state) → 获取下一步教学动作

任务五：建立学习效果评估闭环
在 project/ 目录下新建 learning_evaluation.py，实现学习增益计算和可视化。

核心指标：

python
def compute_learning_gain(pre_score: float, post_score: float) -> float:
    """计算学习增益 = 后测 - 前测"""
    return post_score - pre_score

def compute_learning_efficiency(gain: float, time_spent: float) -> float:
    """计算学习效率 = 增益 / 时间"""
    return gain / time_spent if time_spent > 0 else 0

def compute_learning_roi(gain: float, time_spent: float, effort: float) -> float:
    """计算学习 ROI = 增益 / (时间 * 努力程度)"""
    return gain / (time_spent * effort) if time_spent * effort > 0 else 0
