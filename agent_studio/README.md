# AI 教学 Agent 工作台

一个**能动手的 AI 老师**：它不只讲课，还会现场造教具 —— 图形计算器、分步画板、
可动手操作的虚拟实验室、能跑起来的代码。

**本项目独立运行**，不依赖老项目（那个带 Live2D 模型的界面）。两边唯一的联系是：
老项目如果还在，本项目的工具列表里会多出几个「读老课程教案 / 学生画像」的工具；
老项目不在了就自动摘掉（见 `kernel/tools/lesson.py` 末尾的守卫）。

---

## 快速开始

Windows 双击 **`start.cmd`**，或命令行：

```bash
py -3.14 run.py            # 默认 http://127.0.0.1:5001
py -3.14 run.py --port 5002
py -3.14 run.py --reload   # 改代码自动重启
```

首次使用如果模型连不上，检查 `data/config.json` 里的 API Key；
如果是从老项目迁过来的，运行一次 `py -3.14 migrate_from_legacy.py` 即可把密钥搬过来。

## 界面怎么用

三栏布局（照 DeepSeek Harness 那种工作台的样子）：

```
┌──────────────┬─────────────────────┬──────────────────────┐
│ 我的学习      │  对话                │  工作台              │
│ 📁 数学       │  你：讲讲二次函数     │  老师生成的图表/      │
│  📘 必修一    │  老师：…             │  画板/实验台/         │
│   💬 二次函数 │                     │  图形计算器           │
│   💬 三角函数 │                     │                      │
│ 📁 语文       ├─────────────────────┤                      │
│  📘 古文观止  │  输入框              │                      │
└──────────────┴─────────────────────┴──────────────────────┘
```

- **左栏 = 历史对话**，三级：**学科 → 教材 → 对话**。操作方式跟 IDE / 资源管理器一致：
  - **空白处右键** → 新建学科（文件夹）、刷新列表
  - **学科上右键** → 在该学科下新建教材、重命名学科（F2）、删除学科
  - **教材上右键** → 在该教材下新建对话、新建同科教材、重命名教材（F2）、删除文件夹
  - **对话上右键** → 打开、重命名（F2，就地编辑）、移动到别的学科/教材、删除
  - 双击对话 = 就地改名；右上「＋ 新对话」是个菜单（新建对话 / 新建学科 / 新建教材）
  - **文件夹可以是空的**（先建好分组，之后再往里放对话）；把里面的对话删光，文件夹仍在
- **中栏 = 对话**：Enter 发送，Shift+Enter 换行
- **右栏 = 工作台**：老师要给你看图、画板、实验台时**自动出现在这里**；没有内容时不占位置
- **两条竖线都能拖**调整宽度，双击恢复默认（宽度记在浏览器里）；窄屏自动改为上下堆叠
- 切回某个历史对话时，**聊天记录和上次的工作台内容都会恢复**（界面存在会话里）
- 左栏底部显示当前模型与工具数，点一下可在云端/本地之间切换

对话标题会自动取你的第一句话；想换分组就在左栏点 ✎ 改「标题 / 学科 / 教材」。

## 图形计算器（像 Desmos 一样能自己改公式）

三种打开方式：
1. **自己开**：工作台右上角点 **「＋ 计算器」** —— 立刻得到一台空的计算器，想画什么自己敲，**不用问模型**；
2. 让老师画：说一句「画个圆 x²+y²=16，再画抛物线 y=x²-4」；
3. 老师画完之后，**左边那张公式表是可以直接编辑的** —— 模型只负责把公式写进去，
   剩下的你自己改、自己加，画布当场重画，不用再问一遍。

一行一个公式，支持这些写法：

| 你写 | 出来什么 |
|---|---|
| `y = x^2 - 2x - 3` 或 `x^2` | 函数曲线（`2x`、`3sin(x)` 这种省略乘号也认） |
| `x^2 + y^2 = 16` | 隐式方程 → 圆、椭圆（也认只写左边：`x^2+y^2-16`） |
| `y <= x + 1` | 不等式 → 把区域涂上色 |
| `x^2 + y^2 <= 4` | 圆盘那种隐式区域 |
| `x = 3` | 竖直线 |
| `(2, 3)` | 一个点 |
| `"圆心 O"` 或 `("切点", (1, 2))` | 图上的文字标注（带坐标就放在那儿） |
| `a = 2` | 参数 → 自动出现滑块，公式里写 `a` 就能用 |

好用的小操作：
- **回车**提交这一行并自动开下一行；空行按**退格**删掉这行
- 每行左边的**色块**点一下换颜色，👁 隐藏，✕ 删除
- 画布上**滚轮缩放、按住拖动平移**；鼠标移上去显示坐标，**点在曲线上就加一个点**
- **精确度**：工具栏里选「自动 / 整数 / 1~6 位小数」——坐标刻度和鼠标读数都跟着变
  （想让坐标读成整数就选「整数」；选过一次会被记住）
- **画质**：标准 / 高清 / 超清——曲线和圆画得更细腻，放大时差别最明显
  （拖动/缩放时自动先用标准画质保证跟手，停手后补一帧你选的画质）
- 工具栏：放大 / 缩小 / 重置视野 / 网格开关 / **等比开关**（等比开着圆才是圆）
- 工作台那栏窄的时候，公式表和画布会自动**上下叠**，不会被挤成一条缝
- 每个工作台窗口**右上角有个 ✕**，点掉就能收走旧图（对话记录不受影响）

## 桌面版 + 桌宠（双击就能用）

打包好的是 **`agent_studio/艾琳老师.exe`**（约 53 MB，单个文件，不用装 Python）。

- **双击就起**：自带本地服务（自动挑空闲端口，优先 5001）→ 打开一个**没有地址栏**的应用窗口
  （用 Edge/Chrome 的应用模式；找不到浏览器就退回默认浏览器）→ 桌面上出现一只小角色。
- **桌宠会看你干活**：老师在备课时它歪头想（think）、画好图它说「画好了，去工作台看」、
  交卷会报分数、出错会警觉一下；没人理它 90 秒就打盹。
- **能拖、能点、能说话**：拖到桌面任意位置（位置记住）；**点一下 / 双击打开工作台**；
  右键菜单 → 打开工作台 / 跟艾琳说句话（小聊天框，消息接在你**当前**的对话里）/
  20 分钟后提醒我 / 回到右下角 / 换个配色（原色·薄荷·樱花·夜蓝）/ 隐藏 10 分钟 / 退出。
- **关掉应用窗口它还在**（相当于托盘图标）；想真正结束就点桌宠右键的「退出」。

数据放在哪：按这个顺序找 —— `AGENT_STUDIO_DATA` 环境变量 → **exe 同目录的 `data/`** →
上级的 `agent_studio/data/` → `%APPDATA%\AgentStudio\data`。
所以把 exe 放在 `agent_studio/` 里就**直接接上现有的会话和 API Key**，什么都不用配。
启动时会把选中的目录写进 `data/logs/desktop.log`，出问题先看它。

命令行用法（排查时有用）：

```bash
艾琳老师.exe --check          # 只自检：服务、数据目录、浏览器，全写到日志
艾琳老师.exe --no-pet         # 不起桌宠（只想用界面）
艾琳老师.exe --port 5002      # 指定端口
py -3.14 desktop/build_exe.py                 # 重新打包
py -3.14 desktop/_verify_desktop.py --exe     # 自动验收：起 exe → 截图 → 收工
```

桌宠的形象是**用 Pillow 现场画的**（`desktop/pet_art.py`），仓库里没有图片二进制：
换配色改 `PALETTE`、加表情往 `STATES` 里加。导一张六个表情的对照图看看：

```bash
py -3.14 desktop/pet_art.py --out pet_states.png
```

## 它能做什么（工具即能力）

| 工具 | 干什么 |
|---|---|
| `prepare_course` | **AI 备课**：生成课程目标、单元大纲、每课知识点/公式/易错点/通关问题 + 知识图谱，存成一门课（1~3 分钟） |
| `lesson_context` | 按需取教案：全课目录 / 某一课的详细资料 / 学生跨章画像 / 学习进度 |
| `generate_quiz` | 出随堂测验（选择题，含解析），显示成**点选即判分**的答题卡；成绩自动记入画像 |
| `list_courses` / `open_course` / `course_progress` | 看课程列表 / 打开某门课 / 查看与更新学习进度 |
| `list_conversations` | 查看历史对话与文件夹结构，**标出当前所在的对话**（学生问「我们在哪个文件夹」时用） |
| `search_materials` / `check_link` / `fetch_page` / `download_material` | 上网找教材（真实搜索 + 验证链接）→ 列出候选 → **用户确认后**才下载并转 Markdown |
| `learner_status` / `diagnose` / `plan_next` | 学生画像：掌握度与薄弱点、知识漏洞诊断、下一步该学什么 |
| `record_result` | 记录某题答对答错（掌握度 + 错题记忆），并返回**教学策略建议** |
| `render_ui` | 生成交互界面：分步推导、对照表、答题卡、参数滑块 |
| `graph_calculator` | **图形计算器（推荐）**：一行一个公式就画出来，而且**学生能自己改公式**。支持显函数 `y=x^2`、隐式方程（圆/椭圆）`x^2+y^2=16`、不等式 `y<=x+1`（填色）、竖直线 `x=3`、点 `(2,3)`、文字标注 `"圆心 O"`、参数 `a=2`（自动变滑块）；画布可缩放平移、鼠标移上去读数、点在曲线上就加一个点 |
| `geometry_board` | **可拖的几何画板**：给点和连线，学生**拖顶点**，边长/角度/面积/周长当场变（配 `showSquares` 拖出 a²+b²=c²）。讲勾股、内角和、面积、相似 |
| `data_lab` | **数据统计台**：给一串数，自动算平均数/中位数/众数/极差/方差/标准差并画图，学生**改数字当场变**。演示「改一个极端值，平均数动了、中位数没动」 |
| `solve_equation` | **方程求解器**：把判别式代入、求根公式、因式分解、顶点、韦达定理**一步步展开**并画抛物线，学生**改系数当场重算** |
| `plot_function` | 同上（同一台计算器）的简写入口，只画 y=f(x) 时最短 |
| `draw_board` | 画板：分步作图（几何证明、受力分析），像板书一样一步步长出来 |
| `write_file` | 生成文件（单文件 HTML 仿真、Python 脚本、CSV…），写完**自动自检** |
| `run_python` | 沙箱里真跑代码（超时强杀 + 危险调用拦截），报错回灌给模型自己修 |
| `check_html` | 网页自检：JS 语法 + 常见坑 + 用 Node 桩 DOM 真跑一遍 |
| `show_artifact` | 把产物展示给学生（HTML 在沙箱 iframe 里真的运行起来） |
| `calc` | 数值计算（**模型不准心算**，算数一律走这里） |
| `acid_base_lab` | 插件：酸碱盐虚拟实验室（NOBOOK 风格，真实对数 pH 模型） |

## 加一个新能力

**加工具**（最简单）：在 `kernel/tools/` 新建一个 `.py`，用 `@tool` 装饰器登记，
再到 `tools/__init__.py` 的 `load_builtin_tools()` 里 import 一下。
工具的 JSON Schema 会自动进入模型的工具列表 —— 不用改内核、不用改提示词。

**加插件**（把调试成熟的复杂功能固化下来）：

```
plugins/我的实验/
├── plugin.json     清单：名字、给模型看的描述、工具定义、界面入口
├── handler.py      工具实现（签名同内置工具）
└── ui/index.html   界面（在沙箱 iframe 里运行，单文件自包含）
```

改完调 `POST /agent/plugins/reload` 热加载，**不用重启服务**。

## HTTP 接口

| 接口 | 说明 |
|---|---|
| `GET /` | 三栏工作台界面 |
| `POST /agent/chat` | 对话（SSE 事件流）；`GET /agent/chat?message=...` 便于 curl 调试 |
| `POST /agent/cancel` | 打断当前回合 |
| `GET /agent/sessions` | **历史对话层级树**（学科 → 教材 → 对话），左侧栏用 |
| `POST /agent/folders` | 新建文件夹（学科 / 教材），**允许空文件夹** |
| `POST /agent/folders/rename` | 重命名 / 移动文件夹（里面的对话跟着走） |
| `DELETE /agent/folders` | 删除文件夹（默认连里面的对话一起删） |
| `POST /agent/session/new` | 在某个学科/教材下新建对话 |
| `POST /agent/session/{id}/meta` | 改对话的标题 / 学科 / 教材（重命名、移动分组） |
| `DELETE /agent/session/{id}` | 删除对话 |
| `GET /agent/session/{id}` | 对话详情（历史消息 + 上次的界面，用于切回时恢复） |
| `POST /agent/quiz_result` | 答题卡本地判分后回传，写进学生画像（前端自动调用） |
| `GET /agent/health` | 模型链路 + 工具/插件状态 |
| `GET /agent/version` | **当前服务跑的是哪份代码**（文件时间 + 进程启动时间） |
| `GET /agent/tools` / `GET /agent/settings` | 工具清单 / 当前设置 |
| `POST /agent/settings` | 切换主力模型：`{"llm_provider":"cloud"\|"local"\|"auto"}` |
| `POST /agent/plugins/reload` | 热重载插件 |

## 已知边界（写在明处）

- **多选题会被丢弃**：答题卡目前只支持单选（点一个选项立刻判分）。
  模型偶尔会出「以下哪些说法正确」这种多选题 —— 系统**检测到就丢弃并记日志**，
  而不是让学生点了没反应。要做多选题需要给答题卡组件加多选+提交判分。
- **沙箱不是容器**：`run_python` 靠超时 + 独立工作目录 + AST 黑名单防手滑，
  不是真正的安全隔离。本机单用户教学场景够用，多用户部署需要上容器。
- **本地小模型多轮工具调用不稳**：默认走云端；本地 Ollama 只作兜底。
  内核为此加了两道保险：「只说不做」自动催促、重复调用自动打断。
- **生成的网页可能仍不够好看**：正确性有自检兜底，审美还得人来调 ——
  所以插件机制才重要：调好的版本固化成插件，以后每次都稳定。


这些测试都是**真出过问题**才写的：0 基/1 基错位（讲错课）、答案格式漏判（点了没反应）、
两轴独立拉伸（圆变椭圆）、公式定界符不认（显示原始代码）、等值线连错边（圆画成虚线）。

```bash
node ../data/agent/_cdp_calc_probe.js  # 计算器：点输入框 → 打字 → 回车 → 真的重画
node ../data/agent/_cdp_calc_diag.js   # 逐项隔离诊断：圆/曲线/区域/点/文字各画一遍量像素
```
